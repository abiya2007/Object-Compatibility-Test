<h3>Project Description</h3>

<p>
  Object Compatibility Test is a completely useless web application that
  determines how compatible two objects are.
  Users can enter any two objects or use the Random Input option to generate
  ridiculous combinations, automatically find images, and receive a
  scientifically meaningless compatibility score.
</p>

<h3>The Problem (that doesn't exist)</h3>

<p>
  Objects are constantly being forced to exist without knowing whether they
  are compatible with each other. A banana may have chemistry with a laptop,
  while a chair may secretly be soulmates with a cactus — but nobody has
  bothered to investigate.
</p>

<p>
  Our project solves this completely unnecessary problem by scientifically
  determining whether any two objects are meant to be together.
</p>

<h3>The Solution (that nobody asked for)</h3>

<p>
  We created an Object Compatibility Test that gives two objects a completely
  random compatibility percentage.
</p>

<p>
  Users can enter any two objects or use the Random Input option to generate
  ridiculous combinations. The application automatically finds images for
  the objects and performs a fake "scientific analysis" before revealing
  their compatibility.
</p>

<p>
  The result categorizes the relationship as soulmates, weirdly perfect,
  suspicious chemistry, just friends, toxic relationship, or an absolute
  disaster.
</p>

<h3>Implementation</h3>

<h4>For Software:</h4>

<p>
  The application consists of three main files:
</p>

<ul>
  <li><strong>index.html</strong> – Creates the structure and user interface.</li>
  <li><strong>style.css</strong> – Provides the visual design, animations, buttons and responsive layout.</li>
  <li><strong>script.js</strong> – Handles user input, random objects, image fetching, compatibility calculation and results.</li>
</ul>

<p>
  When the user enters two objects, JavaScript sends a search request to the
  Wikimedia Commons API and displays a relevant image for each object.
</p>

<p>
  When the user clicks "Test Compatibility", the application performs a
  fake two-second analysis and generates a random compatibility score between
  50% and 99%.
</p>

<p>
  The score is then converted into a humorous relationship category and
  displayed together with a compatibility meter.
</p>

<h3>How to Use</h3>

<ol>
  <li>Enter the name of the first object.</li>
  <li>Enter the name of the second object.</li>
  <li>The application attempts to find images automatically.</li>
  <li>Click <strong>Test Compatibility</strong>.</li>
  <li>Wait for the fake scientific analysis.</li>
  <li>View the compatibility percentage and relationship result.</li>
  <li>Use <strong>Try Again</strong> or <strong>Random Input</strong> to test another pair.</li>
</ol>
